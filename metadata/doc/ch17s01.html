17.1. Printing a Custom Label

A custom label is a label on which certain information (such as the Patient ID, or the dosage of a drug) is typed manually by the user, and not generated automatically by the system. This type of label is not associated with any other transaction in the system, such as the preparation of a package - this function exists only to allow the user to create custom labels in special circumstances. It does not talk to the database except to retreive the pharmacy details.

Printing of emergency package cover, drug or patient labels takes place from the Print an Emergency Label screen. From the main screen, select Stock Control . This will bring up the Stock Control screen - from this screen, select Make up ARV Packages for Patients . This will bring up the Make up ARV Packages for Patients screen. From this screen, select Create Emergency Label. The Create Emergency Label screen looks like this:

First, select the kind of label you want to print. The editable areas are the areas of the label with a gray background. Clicking in one of these areas allows you to edit the text in this area. Note that for the package label, the Package ID will be replaced by the barcode representing it, and also printed in plain text below the barcode.

Once you have a label that contains all the correct information, you can select the number of labels you wish to print for this patient from the drop-down box. Then, select Print to print the label(s). You will be prompted to select a printer; do this and press Print .

To clear all the text fields, press Clear . To leave the screen without printing any labels, press Cancel .
