8.1. Adding Stock

The Stock Arrives screen must be used to add the stock to the database. Before adding stock of a drug, it is important to add the drug itself using the Add a New Drug screen, if this has not already been done. For more information on this, see Adding Drugs. It is also important that the distribution clinic for which the stock is intended has been added. For more information on this, see Adding Distribution Clinics. To add stock, log into the system and select Stock & Dispensing from the main screen. A new screen, the Stock Control Screen, will appear. From this screen, select Stock Arrives . The Stock Arrives at Pharmacy screen will appear. It looks like this:

This screen displays a list of all the stock being added during the current session. For each batch, the user must perform the following steps:

  • Click Add Stock on the Stock Arrives at Pharmacy Screen (above). The Add Stock screen appears. It looks like this:

  • Use the Drug Search button to select the drug
  • Fill in the batch information in the lower half of the screen

When you are finished, click Save to add the stock batch. To clear all the text fields, press Clear . To leave the screen without saving the stock batch, press Cancel . You will now be returned to the Stock Arrives at Pharmacy screen. If you have successfully added stock, it should appear in the list on this screen. If it has not appeared, or to add another batch of this or another drug, click Add Stock and repeat the steps above.

If you have made a mistake and wish to remove a batch from the list of batches to be saved, click the batch in the stock list to select it, and click the Remove Selected Batch button.

Once you have finished adding all the stock you wish to add in this session, click Submit to save the stock. If you want to leave this screen without saving anything (all the stock you entered will be lost), click Cancel .

When you click Submit, a Stock Receipt report can generated, showing all the stock that has been entered on this day. You should check the Stock Receipt Report to be sure that the stock arrival has been recorded correctly. You can then print or save this report. See the section Printing and Saving Reports for further information about this.
