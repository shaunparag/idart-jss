12.1. Manage Pharmacy Users

The Manage Pharmacy Users screen allows the currently logged in user to

  • Change their password
  • Add a new iDART user

To access this screen, select General Admin from the main screen. A new screen, the General Admin Screen, will appear. From this screen, select Manage Pharmacy Users . The Manage Pharmacy Users screen will appear. It looks like this:

12.1.1. To add a new user:

Select the Add New iDART User radio button. Enter a username for the new user in the Username field, and then enter their password in the password and confirm password fields. The text in the two fields must be identical. Note that characters in passwords appear as * symbols when entered, to prevent anyone from seeing the password being typed.

When you are finished, click Save to add the new user. To clear all the text fields, press Clear . To leave the screen without adding a new user, press Cancel .

12.1.2.  To change the password of the currently logged in user:

Select the Change Your Password radio button. Enter your old password, then enter you new password in the New Password and Confirm New Password fields. The text in the last two fields must be identical. Note that characters in passwords appear as * symbols when entered, to prevent anyone from seeing the password being typed. When you are finished, click *Save* to add the new user. To clear all the text fields, press Clear . To leave the screen without adding a new user, press Cancel .
