18.11. Printing and Saving Reports

Reports will open in a window like the one below:

You can view the report in this screen, and also print or save it. In the image below, the left button is the save button, and the right button is the print button.

18.11.1. To print the report:

Click on the printer button in the icon bar at the top of the viewer. The button is second from the left. This will bring up a screen that will let you choose a printer and associated settings. It looks like this:

18.11.2. To save the report:

Click on the save button in the icon bar at the top of the viewer. The button is the first from the left hand side. This will bring up the following screen:

You can select the file format in which the report should be saved from the drop-down list (shown dropped down in the image). The recommended format is PDF, which can be read by Adobe Acrobat and a number of free viewers, such as xpdf, but cannot be modified. Choose a file format, and give the file a name. Also navigate to the place you want to save the file, and then press Save .
