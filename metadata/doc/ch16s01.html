16.1. Stock, Prescription and Package Deletions

You can perform 4 types of deletions in iDART. These are:

  • Package Deletions : Delete the most recent package for a patient, for example when the patient fails to collect their drug package.
  • Single Package Item Deletions : Delete an item in the most recent package for a patient.
  • Prescription Deletions : Delete a patient's incorrectly captured prescription, if this prescription has not been dispensed
  • Stock Batch Deletions : Delete an incorrectly captured stock batch, if no drugs have been dispensed from this batch

All the above deletions require the currently logged in user to provide their password before the deletion occurs. A log of the deletion is also created, and a report showing all logged deletions for a time period can be viewed by selecting Transaction Log Report from the Reports screen.

To perform a deletion, select Stock & Dispensing from the main screen. Then, select Stock,Prescription And Package Deletions. You should see the following screen:

16.1.1. To perform a package deletion:

Select the Return Uncollected Packages radio button. Enter a Patient ID, or use the patient search to select the patient whose package you want to remove. The most recent package for this patient, if any, will be shown, as well as the drugs the package contains. To remove the package, select Remove this Package . If you do not wish to remove a package at this time, select Cancel .

16.1.2.  To perform a single package item deletion:

Select the Red Single Item in Package radio button. Enter a Patient ID, or use the patient search to select the patient whose package item you want to remove. The most recent package for this patient, if any, will be shown, as well as the drugs the package contains. To remove an accumulated or dispensed drug, select the row containing that drug's information and click Remove this Drug . If you do not wish to remove a package item at this time, select Cancel .

16.1.3. To perform a prescription deletion:

Select the Delete Incorrect Prescription radio button. Enter a Patient ID, or use the patient search to select the patient whose prescription you want to remove. Any prescription for this patient that can be removed (i.e. has not yet been dispensed) will be shown, as well as the drugs on the prescription. To remove the prescription, select Remove this Prescription . If you do not wish to remove a prescription at this time, select Cancel .

Please note that you cannot remove just one drug in a prescription - the entire prescription must be removed and redone.

16.1.4. To perform a stock batch deletion:

Select the Delete Incorrect Stock Batch radio button. Use the Drug Search button to select the drug for which you wish to remove a batch. Any batches for this drug that can be removed (i.e. has not yet been dispensed) will be shown, To remove a batch, click the batch in the list and select Remove Selected Batch . If you do not wish to remove a stock batch at this time, select Cancel .
