18.6. Monthly Clinic Indicator Report

The Monthly Clinic Indicator Report shows statistics for each clinic, for a certain month. This is divided into paediatric and adult patient statistics. The report also contains regimen information, which relies on correctly defined Drug Groups (see Drug Groups)

To see a Monthly Clinic Indicator Report , select Reports from the main screen. This will open the Reports screen. From the Reports screen, select Monthly Clinic Indicator Report . The Monthly Clinic Indicator Report screen will open. It looks like this:

You should select a distribution point from the drop-down list, and also set values for the parameters:

  • Minimum Days Late, which is the shortest length of time that must elapse after a patient was expected to collect a package, for them to be considered a defaulter.
  • Cutoff Age For Paediatric Patients

Then, select View Report to see a Monthly Clinic Indicator Report for the distribution point and parameters you have specified (or Cancel to return to the Reports Screen).

The report will open in a Report Viewer. You can now print or save the report. For information about this, please see Printing and Saving Reports.
