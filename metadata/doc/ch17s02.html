17.2. Troubleshooting Label Printing

Please note that the system is designed to use labels of size 3" by 2", and the Zebra range of label printers. These instructions apply to this printer, although they may still be useful if you have a different label printer. Please also note that these instructions are for computers running Microsoft Windows XP.

If you need to be talked through these procedures, or if this does not solve your problem, please call the Cell-Life iDART help desk (see How to Get Help).

17.2.1.  Setting your label printer as the default printer:

Zebra printers seem to work better when set as the default printer. This is usually the first thing to try when you experience printing problems. To set your label printer as the default printer, do the following:

Go to Start Programs, then Control Panel. This will bring up the Windows control panel. Click on Printers and Other Hardware, then View Installed Printers And Faxes. This should show all your installed printers. Use the right mouse button to click on the printer that prints your labels. This should bring up a menu – select Set as Default to set this printer as your default printer.

17.2.2.  Setting the label size for your label printer:

If your labels are not printing correctly, you may need to reset the paper size on your printer. To do this, go to Start Programs, then Control Panel. This will bring up the Windows control panel. Click on Printers and Other Hardware, then View Installed Printers And Faxes. This should show all your installed printers. Use the right mouse button to click on the printer that prints your labels. This should bring up a menu - select Properties, one of the last items on this menu. You should see the printer properties screen. Select Printing Preferences. The screen you see should look something like this:

Click the + sign next to Paper/Output. This will show you the paper settings. Click on the paper size (blue, underlined text) to change this. Set the paper size to 2" x 3".
