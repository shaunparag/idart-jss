Chapter 1. Welcome to the iDART Pharmacy Tool

iDART (which stands for the Intelligent Dispensing of Antiretroviral Treatment) is a tool designed to help pharmacists and pharmacy assistants with the monthly dispensing of antiretroviral drugs. iDART is designed in the context of a resource constrained environment, the public health sector in South Africa. iDART seeks to address many of the problems typical of this type of environment. The development of iDART was the result of collaboration work between Cell-Life and the Desmond Tutu HIV Centre, in Cape Town, South Africa. iDART is an open source project and the source code can be downloaded from http://idart.Cell-Life.org. It is released under GPL, so please feel free to distribute this program under its license agreement. Any thoughts or comments would be greatly appreciated. Please send these to idart@cell-life.org.za.
