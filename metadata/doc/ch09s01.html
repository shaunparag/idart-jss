9.1. Adding Doctors

Doctors are added using the Add A New Doctor screen. From the main screen, select General Admin . A new screen, the General Admin Screen, will appear. From this screen, select Add a new Doctor . The Add a New Doctor screen will appear. It looks like this:

Fill in at least the doctor's name and surname (the compulsory fields, marked with ). The other fields are recommended, but not required. When you are finished, click *Save to add the doctor. To clear all the text fields, press Clear . To leave the screen without saving the doctor, press Cancel .
