9.2. Updating a Doctor's Information

A doctor's information can be updated using the Update an Existing Doctor screen. From the main screen, select General Admin . A new screen, the General Admin Screen, will appear. From this screen, select Update an Existing Doctor's Details . The Update an Existing Doctor screen will appear. It looks like this:

Fill in at least the doctor's name and surname (the compulsory fields, marked with ). The other fields are recommended, but not required. When you are finished, click *Save to save your changes to the doctor. To clear all the text fields, press Clear . To leave the screen without saving the doctor, press Cancel .
