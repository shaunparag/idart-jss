15.3. Pre-packaging for patients at Remote Clinics

(Please note that this section is only relevant to versions of iDART using the remote dispensing feature)

If you are pre-packaging for patients who collect their drugs at remote clinics, the system tracks packages by recording four dates:

  • The date the package was packed
  • The date the package left the pharmacy
  • The date the package arrived at the remote clinic
  • The date the package was picked up by the patient.

Packages that have been pre-packed must be scanned using a barcode scanner as they leave to record the second date. The third and fourth dates are recorded when the package is scanned at the clinic using the iDART clinic application.

To record a package leaving the pharmacy, select Stock & Dispensing from the main screen. From the Stock Control screen, select Scan Out Packages To Remote Clinic . This will cause the Distribute ARV Packages screen below to open.

First, select a clinic from the drop-down list. This will cause the Package IDs of all the packages waiting to leave for this clinic to appear in the list on the left. Use a barcode scanner to scan the package IDs of the packages that will leave the pharmacy now. Note that in the event of problems with scanning, you can type the Package IDs in by hand.

When you have finished scanning, you can choose View Report of Packages Dispensed to see a report of the packages that have left the pharmacy today. You can print or save the report - please see Printing and Saving Reports for further information on this. If you wish to leave this screen without seeing a report, you can choose Close .
