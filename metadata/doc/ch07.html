Chapter 7. ARV Drugs

The system stores all the ARV drugs that will be given to patients. The drug is referenced by its name, which should therefore include the abbreviation and strength. For example, you might have [d4t] Stavudine 30mg. You need to specify the chemical compounds in the drug, fill in the pack size, and select the form (tablets, solution etc) as this determines the dosage instructions that will be printed on the drug label. You can optionally specify a standard dosage for the drug. Before the existing stock of a drug can be recorded, it must be added as shown in this section. If you are unsure about drug attributes, try looking at the example with fields filled in, found in the Adding Drugs section.
