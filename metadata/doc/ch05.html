Chapter 5.  Getting Started: Updating Pharmacy Details And Adding Drugs, Stock, Doctors, Patients and their Prescriptions

The Basic Concepts section describes tasks you will need to perform to set up the system for your pharmacy. First, the pharmacy's details (such as address, telephone number etc) must be entered. Then, the ARV drugs that will be dispensed to patients (such as Efavirenz 200mg Capsules, Kaletra Solution etc) must be added. Once the drugs have been added, the stock levels for each drug must be recorded. If you would like iDART to store regimen information, you will also need to define the groups of ARV drugs that can be prescribed as regimen 1A, 1B or 2.

Patients must be added next, followed by the doctors who will prescribe drugs to the patients. Existing prescriptions for the patients must then be recorded.
